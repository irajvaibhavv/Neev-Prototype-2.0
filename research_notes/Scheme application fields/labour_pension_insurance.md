# Scheme form fields (labour / pension / insurance) - researched 2026-09-30
Basic identity (name, DOB, gender, Aadhaar, mobile, address) asked everywhere unless noted.
Status: C = CONFIRMED (read on official form/page), U = UNVERIFIED (news/aggregator/search summary).

## PMSBY (C) - https://www.jansuraksha.gov.in/Files/PMSBY/PMSBY_Enrollment_Form.pdf (read full text)
| Field | Status |
|---|---|
| Account holder name, father's/husband's name | C |
| Bank/PO account no., IFSC of branch | C |
| PAN (if available), Aadhaar (if available), DOB, e-mail | C |
| Disability? yes/no + details | C |
| Nominee: name+address, DOB, relationship | C |
| Nominee mobile, email | C |
| If nominee minor: guardian/appointee name+address, relationship, mobile, email | C |
| KYC proof copy (Aadhaar / EPIC / MGNREGA / DL / PAN / Passport) | C |
| Auto-debit consent Rs 12/yr; declaration no other bank debits | C |
Bank account REQUIRED: YES - premium auto-debited from the account. Age limit/eligibility text not on form (U).

## PMJJBY (C) - https://www.jansuraksha.gov.in/Files/PMJJBY/PMJJBY_Enrollment_Form.pdf
Same as PMSBY minus the disability question. Premium Rs 436/yr (form text says Rs 330 - old; U for current amount). 30-day lien period. Bank account REQUIRED: YES (auto-debit).

Bank account REQUIRED: YES (auto-debit till age 60). Age 18-40 (U, from memory/search).

## PM Shram Yogi Maandhan (U) - official maandhan.in/shramyogi returned 404; jansuraksha-style fetch failed
Fields (search summaries of CSC/VLE enrolment, not official page): Aadhaar, name per Aadhaar, DOB, mobile, email, savings/Jan Dhan account no. + IFSC, spouse details, nominee details (name, relationship) - U. Eligibility: 18-40 yrs, income <= Rs15,000/mo, not EPFO/ESIC/NPS member - U. Docs: Aadhaar, bank passbook/cheque/statement - U. Bank account REQUIRED: YES (savings/Jan Dhan; auto-debit) - U.

## e-Shram (U) - eshram.gov.in landing fetch returned only language selector
Fields (search summaries): Aadhaar-linked mobile (OTP), bank account+IFSC, education level, primary + secondary occupation (NCO), skills, work experience, current + permanent address, nominee (name, relationship, DOB, contact) - U. Docs: Aadhaar + Aadhaar-linked mobile only; bank details entered (no upload) - U. Bank account: asked; effectively needed for benefits - U (some sources say optional; not confirmed).

## BOCW Delhi (partial C) - https://bocw.delhi.gov.in/bocw/procedure-registration-and-renewal-membership
C: age 18-60; 90 days work in last 12 months; docs: age proof (voter ID/ration card/DL or notarised affidavit), local address proof (ration card, bank passbook, utility bill, ID etc.), 90-day employment certificate (employer/contractor, union, or self-certificate). Fee Rs25 first yr, Rs20 renewal. Page lists NO nominee/bank fields (C: absent from that page). Form XXVII field list not read -> nominee/bank/dependants/photo fields UNVERIFIED. Bank account: not stated (U).

## BOCW UP (U) - upbocw.in not fetched; only aggregator/search summaries
Aadhaar, district, mobile, captcha; name, father's name, address; bank passbook (16-digit a/c), employment/90-day certificate, photo, self-declaration; one family member as nominee (U). Bank account likely required for benefit DBT (U).
