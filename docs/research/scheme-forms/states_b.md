Legend: C = CONFIRMED on official page read; U = UNVERIFIED (news/aggregator/memory). Basic identity (name, DOB, gender, Aadhaar, mobile, address) assumed asked everywhere.

## 1. UP Kanya Sumangala (mksy.up.gov.in/women_welfare/ - read)
| Field | Status |
|---|---|
| Aadhaar of applicant, father, mother AND beneficiary daughter(s) mandatory (from 10-Oct-2022) | C |
| Family = UP resident (proof: ration card/Aadhaar/voter ID/utility bill) | C |
| Annual family income <= Rs 3 lakh (declaration/cert) | C (eligibility) |
| Max 2 children / 2 girls; twins / adopted-orphan provisions (child count, birth order) | C (eligibility) |
| Daughter DOB/birth stage, school class/enrolment, bank a/c of mother/guardian, income cert, birth cert | U |
Bank account: U (yes - DBT, memory). Application on Citizen Services Portal (form fields not shown on page fetched).
