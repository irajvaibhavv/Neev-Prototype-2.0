2-minute demo

  1. Open the Employee app, pick a language, sign up with any 10-digit number (OTP fills itself).
  2. Tap Government schemes → scan or enter Aadhaar → answer the quick questions → see eligible schemes.
  3. On 1–2 schemes tap Apply via Neev → fill the form → upload some documents (skip one) → Add to cart → open the 🛒 cart → Pay.
  4. Open the Manager dashboard in a new tab of the same browser → your applications appear tagged LIVE in New (all documents) or Pending (document skipped). Open one → send a WhatsApp reminder, remove it, or mark it Filled → Approved.
Prototype limitation: the app and dashboard share data only inside the same browser on the same device (no server yet). A phone and a laptop won't see each other's data. The dashboard also shows ~500 sample users so the funnel looks realistic — untick Include sample data to see only your own.
